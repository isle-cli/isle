Isle

Isle is an MCP server and a CLI that gives an AI agent the ability to launch and trade tokens on Montra, on Elysium. You talk to Claude, ChatGPT, Cursor, or any MCP client in plain language, and the agent calls the tools.

Early. No users beyond its author. Not yet approved as a Montra builder.

Give your agent a wallet

The agent does the clicking. The tools are typed and named, and the key stays in a file on your machine that the agent never sees.

Install

The server is built from the repository with npm install && npm run build, and it is not on npm yet.

claude mcp add isle -- node dist/mcp.js
{
  "mcpServers": {
    "isle": {
      "command": "node",
      "args": ["dist/mcp.js"]
    }
  }
}

Rails

  • Dry run by default.
  • A maxSpendHype cap in the config.
  • Every transaction is simulated first.
  • Refusals are returned as readable text.
  • The key is read from a file.

Limitations

  • firstBuyMinOut is 0, so the first buy of a launch has no slippage floor.
  • Images and metadata go to a third party IPFS service.
  • The default RPC is a single unofficial endpoint.
  • There is no allowance revocation after a trade.
  • The server is stdio and local only, with no hosted endpoint yet.
