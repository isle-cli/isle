Isle

Isle is a command line tool for launching and trading tokens on Montra, a launchpad on the Elysium chain, with no users beyond its author and not yet approved as a Montra builder.

git clone https://github.com/isle-cli/isle.git
cd isle
npm install
npm run build

How it works

  1. Clone the repository and build it.
  2. Set a key.
  3. Dry run, then send.

Commands

node dist/index.js configs

Lists launch configurations.

node dist/index.js launch

Launches a token.

node dist/index.js quote

Quotes a trade.

node dist/index.js buy

Buys a token.

node dist/index.js sell

Sells a token.

Safety

  • Every transaction is simulated before it is sent.
  • --dry-run prints calldata and sends nothing.
  • The chain id is checked.

Limitations

  • firstBuyMinOut is 0, so the first buy of a launch has no slippage floor.
  • Images and metadata go to a third party IPFS service.
  • The default RPC is a single unofficial endpoint.
  • There is no allowance revocation after a trade.
