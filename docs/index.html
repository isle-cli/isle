MCP server · Elysium

Give your agent a wallet.

Isle is an MCP server and a CLI for Claude, Cursor, and ChatGPT. The agent launches and trades tokens on Montra, on Elysium.

Early. No users beyond its author. Not yet approved as a Montra builder.

Install

git clone https://github.com/isle-cli/isle.git
cd isle
npm install
npm run build
claude mcp add isle -- node dist/mcp.js

Not on npm yet. The key stays in a file on your machine.

Every mutating tool takes send, default false.

Rails

  • Dry run by default.
  • A maxSpendHype cap.
  • Every transaction is simulated first.
  • Refusals come back as readable text.
  • The key is read from a file.

Limitations

  • firstBuyMinOut is 0, so a first buy has no slippage floor.
  • Images and metadata go to a third party IPFS service.
  • One unofficial RPC by default.
  • No allowance revocation after a trade.
  • Stdio and local only.
